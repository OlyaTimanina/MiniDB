# MiniDB --- упрощённая система управления базами данных

## 1. Описание проекта

MiniDB --- это учебная система управления базами данных, разработанная
на языке Java.

Программа позволяет создавать и удалять таблицы, добавлять, изменять,
удалять и просматривать записи с помощью SQL-подобных команд.

Данные сохраняются на диске и автоматически загружаются при следующем
запуске программы.

В проекте реализованы: - Работа с несколькими таблицами. - Поддержка
типов данных INTEGER, DOUBLE, STRING, DATE и BOOLEAN. - Первичные и
внешние ключи. - SQL-команды CREATE TABLE, DROP TABLE, INSERT, SELECT,
UPDATE и DELETE. - Условия поиска WHERE. - Индексация столбцов с помощью
CREATE INDEX. - Сохранение и загрузка базы данных. - Консольный
интерфейс.

## 2. Архитектура проекта

Проект состоит из нескольких основных компонентов:

-   `Main` --- точка входа в программу, отвечает за взаимодействие с
    пользователем.
-   `Database` --- управляет таблицами базы данных.
-   `Table` --- хранит структуру таблицы, записи и индексы.
-   `Column` --- описывает столбцы и их свойства.
-   `Row` --- хранит значения одной записи.
-   `DataType` --- определяет поддерживаемые типы данных.
-   `SQLParser` --- анализирует SQL-команды.
-   `SQLExecutor` --- выполняет SQL-команды.
-   `QueryResult` --- формирует и выводит результаты запросов.
-   `StorageManager` --- отвечает за сохранение и загрузку базы данных.
-   `Benchmark` --- выполняет тестирование производительности поиска.

## 3. Поддерживаемые SQL-команды

**1. Создание таблицы**

``` sql
CREATE TABLE students (id INTEGER PRIMARY KEY, name STRING NOT NULL)
```

**2. Удаление таблицы**

``` sql
DROP TABLE students
```

**3. Добавление записи**

``` sql
INSERT INTO students (id, name) VALUES (1, 'Anna')
```

**4. Просмотр всех записей**

``` sql
SELECT * FROM students
```

**5. Поиск по условию**

``` sql
SELECT * FROM students WHERE id = 1
```

**6. Изменение записи**

``` sql
UPDATE students SET name = 'Maria' WHERE id = 1
```

**7. Удаление записи**

``` sql
DELETE FROM students WHERE id = 1
```

**8. Создание индекса**

``` sql
CREATE INDEX idx_student_id ON students (id)
```

Индексы позволяют ускорить поиск записей по выбранным столбцам.

## 4. Поддерживаемые типы данных

В MiniDB реализована поддержка пяти типов данных:

-   INTEGER --- целые числа.
-   DOUBLE --- вещественные числа.
-   STRING --- текстовые значения.
-   DATE --- даты в формате LocalDate.
-   BOOLEAN --- логические значения (true или false).

### Ограничения целостности данных

В проекте реализованы следующие ограничения:

-   PRIMARY KEY --- первичный ключ, значения которого должны быть
    уникальными.
-   NOT NULL --- запрещает добавление пустых значений.
-   REFERENCES --- внешний ключ, связывающий таблицы между собой.

При добавлении записи программа проверяет корректность типов данных,
уникальность первичных ключей и существование значений внешних ключей в
связанных таблицах.

## 5. Связь между таблицами

Для демонстрации связи между таблицами используются две таблицы:
`students` и `courses`.

Таблица `students` хранит информацию о студентах: - `id` --- уникальный
идентификатор студента. - `name` --- имя студента.

Таблица `courses` хранит информацию о курсах: - `id` --- уникальный
идентификатор курса. - `title` --- название курса. - `student_id` ---
идентификатор студента, которому принадлежит курс.

Поле `student_id` является внешним ключом и ссылается на поле `id`
таблицы `students`.

Таким образом, одна таблица связана с другой через внешний ключ.

## 6. Индексация и тестирование производительности

В MiniDB реализована индексация столбцов с помощью команды
`CREATE INDEX`.

Индекс хранится в виде хеш-таблицы `HashMap`, которая связывает значения
столбца с соответствующими записями.

При выполнении запроса `SELECT ... WHERE` программа сначала пытается
найти подходящий индекс. Если индекс существует, поиск выполняется с его
использованием. Если индекса нет, программа перебирает записи таблицы.

### Результаты тестирования

Тестирование проводилось на таблице из 50 000 записей. Выполнялось 500
поисковых операций.

Первый запуск: - Без индекса --- 870 мс. - С индексом --- 1 мс.

Второй запуск: - Без индекса --- 804 мс. - С индексом --- 1 мс.

Третий запуск: - Без индекса --- 865 мс. - С индексом --- 1 мс.

Среднее время поиска без индекса составило примерно 846 мс, с индексом
--- около 1 мс.

Результаты показывают, что использование индекса значительно ускоряет
поиск записей по сравнению с последовательным перебором таблицы.

Время создания индекса в данном тестировании не учитывалось.

## 7. Инструкция по запуску

Для запуска проекта необходима установленная Java версии 21 или выше и
IntelliJ IDEA.

Порядок запуска:

1.  Открыть проект MiniDB в IntelliJ IDEA.
2.  Убедиться, что для проекта выбрана Java 21 или выше.
3.  Открыть класс `Main`.
4.  Запустить метод `main`.
5.  После запуска в консоли можно вводить SQL-команды.

При первом запуске программа автоматически создаёт новую базу данных.

Данные сохраняются в файл `minidb.dat`. При следующем запуске программа
автоматически загружает сохранённую базу данных.

Для завершения работы необходимо ввести команду `EXIT`.

## 8. Ограничения проекта

MiniDB является учебной упрощённой реализацией системы управления базами
данных, поэтому обладает рядом ограничений:

-   Поддерживается поиск по одному условию равенства `WHERE`.
-   Для выборки поддерживается команда `SELECT *`.
-   Не реализованы сложные SQL-операторы, такие как `JOIN`, `GROUP BY`,
    `ORDER BY`, `AND` и `OR`.
-   Индексы создаются для отдельных столбцов.
-   Проверка внешних ключей выполняется при добавлении записей.
-   Проект не предназначен для одновременной работы нескольких
    пользователей.
